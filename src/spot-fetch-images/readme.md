# Spot Fetch Images – `fetch.py`

This folder contains `fetch.py`, a Python script to **fetch real-time images** from the **REAL Spot robot** during arm manipulation activities. **This folder is primarily used for testing the effectiveness of image retrieval in the system, serving as a unit test for the subsequent validation process.**

## Overview

The script connects to the Spot robot's camera system and continuously retrieves image frames while the robot is performing manipulation tasks. This is useful for monitoring, logging, or computer vision-based analysis.
